# ALFABETIC — Primera versión jugable

Aplicación web de alfabetización inicial: cinco niveles, ocho desafíos por nivel (40 en total).

## Ejecutar

Abrir `index.html` en Chrome, Edge, Firefox o Safari. No requiere instalación, servidor ni conexión a Internet para la interfaz y las actividades. La síntesis de voz depende del navegador y de las voces instaladas; algunos sistemas pueden necesitar conexión para ciertas voces.

## Funcionalidades

- Bienvenida y presentación de Ana, Mateo y Luxi.
- Mapa con cinco mundos y acceso libre a todos.
- Diagnóstico, vocales, sílabas, palabras y oraciones.
- Preguntas de selección, escritura y ordenamiento por pulsación.
- Retroalimentación, reintentos, recompensas y progreso local (localStorage).
- Diseño adaptable a pantallas de computadora y celular.

## Alcance y pendientes

Este es un **prototipo funcional inicial para revisión**, no una versión final validada pedagógicamente. Las actividades requieren revisión docente y pruebas con distintos navegadores. Las voces son generadas por el navegador, no grabaciones humanas. Las representaciones de personajes son provisionales (emoji); las ilustraciones definitivas pueden incorporarse después. El diagnóstico es orientativo y no sustituye una evaluación docente individual. El sistema no incluye perfiles individuales, backend ni estadísticas avanzadas.

## Pruebas recomendadas

1. Abrir el archivo y comprobar que aparecen los personajes.
2. Entrar en cada mundo y completar sus ocho desafíos.
3. Probar respuestas incorrectas, reintentos, escritura y ordenamiento.
4. Volver al mapa, recargar la página y comprobar el progreso.
5. Abrir en celular y verificar la navegación.
6. Probar audio con y sin voces disponibles.

## GitHub

Subir `index.html` y `README.md` a un repositorio. Para publicarlo con GitHub Pages, elegir `Settings > Pages > Deploy from a branch` y seleccionar la rama principal y carpeta raíz. No publicar DNI u otros datos personales sensibles en repositorios públicos.
